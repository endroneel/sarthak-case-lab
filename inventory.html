Why the loss function matters

For a normally distributed demand variable, the standard normal loss function is:

L(z) = φ(z) − z[1 − Φ(z)]
E[lost sales] = σL(z)
E[sales] = μ − E[lost sales]
E[leftover] = Q − E[sales]

The inventory model separates the cost of producing too much from the opportunity cost of producing too little. The pricing page then monetises both effects.

Do not round expected lost sales. An expected value such as 0.601 is an average across many possible demand outcomes. Artificially rounding it changes the profit curve and can change the recommended quantity.
